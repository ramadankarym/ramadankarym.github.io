## ✨ المميزات

- 🕐 عداد تنازلي لحظة بلحظة لبداية الشهر الكريم، مع مواقيت رمضان
- 🎬 ١٥ قالب فيديو تهنئة مختلفة: فوانيس، مسجد، هلال ذهبي، سفرة إفطار، مسبحة، ساعة رمضان وأكثر
- 📐 أربعة مقاسات: ستوري ٩:١٦، فيسبوك ٤:٥، مربع ١:١، وعريض ١٦:٩
- 🔤 اختيار حجم الخط (صغير / وسط / كبير) تحت كل خانة نص، والنص الطويل بيتظبط تلقائيًا ومبيخرجش برة التصميم
- 👀 معاينة حية للفيديو وانت بتكتب وبتغيّر القالب والمقاس وحجم الخط
- 🌍 الموقع والفيديو بالعربي والإنجليزي
- ✅ مجاني ١٠٠٪، بدون تسجيل ولا اشتراك، وبدون علامة مائية
- 📱 يعمل من الموبايل مباشرة
- 🎵 موسيقى رمضانية هادئة اختيارية

اكتب اسمك، اختار القالب والمقاس، وحمّل الفيديو وشاركه مع أهلك وأصحابك 💛
